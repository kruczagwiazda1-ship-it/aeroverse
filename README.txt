Aeroverse for Wii U (Aroma homebrew) - version 2.0

Looks like the website: sky background, glass cards, the same fonts, logo and icons.
Tabs: Home (world clock globe, Most liked, Drawings of the week, Latest posts), Communities,
Plaza (3D island with walking people), Games (Super / Ultra Wiggle Paint), Profile / Sign in.
Posts show their styles 1:1 (colours, 8 themes, 29 fonts, sizes, frames, bold/italic/colour/glow/gradient...).
NEW POST editor with Format / Text / Effects / Post / Layout rows and a live preview.
Drawing editor like the website: 8 tools, 32 colours, sizes, grid, undo/redo, wiggle 1-5,
Super and Ultra Wiggle Paint with the chaos effects.

GitHub Actions builds aeroverse_stage1/2/3.wuhb (artifact "aeroverse_wiiu") and publishes a release.
The app checks that release on start and offers "tap to update" on Home.
Copy the app to the SD card as  wiiu/apps/aeroverse.wuhb  (exactly this name, needed for updates).
