Aeroverse for Wii U (Aroma homebrew)

Tabs like the website: Home, Communities, Plaza, Games, Profile / Sign in.
Stage 1: reading (posts, communities, replies, drawings, Plaza, profiles)
Stage 2: + sign in, posts, replies, Yeah!, drawing in posts (with Wiggle)
Stage 3: + Games: Super / Ultra Wiggle Paint

GitHub Actions builds all three: aeroverse_stage1/2/3.wuhb (artifact "aeroverse_wiiu")
and publishes a release that the app uses to update itself.
Copy ONE of them to the SD card as  wiiu/apps/aeroverse.wuhb
Controls: touch, D-Pad + A, B back, L/R tabs, Y refresh, X Yeah!, + send.
