Aeroverse for Nintendo 3DS (Homebrew Launcher) - version 1.3

Same account, posts, communities and drawings as the website and the Wii U app.
Top screen: the selected post / drawing / community, big. Bottom screen (touch): lists, buttons, drawing.
Tabs: Home, Communities, Plaza (island with walking people), Games (Super / Ultra Wiggle Paint), Profile / Sign in.
Write posts and replies with the 3DS keyboard, add a drawing (with wiggle) drawn with the stylus, give Yeah!s.
Super / Ultra Wiggle Paint: draw on the bottom screen while it shakes, flips and changes colour.

Buttons: L / R change tab, D-pad + A choose, B back, X write / reply, Y Yeah!, START exit.
Posts: tap once to see it on the top screen, tap again to open it.

GitHub Actions builds aeroverse.3dsx (artifact "aeroverse_3ds") and publishes a release "3ds-build-N".
Copy it to the SD card as  3ds/aeroverse.3dsx  and start it from the Homebrew Launcher.
The app checks GitHub on start and offers "tap to update" on Home.
